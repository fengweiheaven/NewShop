【一、联网与账号】

3、新增保存冲突保护：两人同时改数据时，后保存的一方弹窗提示「数据冲突」，不会静默覆盖
4、新增账号菜单：修改昵称、成员与角色、退出登录；并显示当前版本号

【二、商品】
7、商品库按「商品池」标准 30 列表头展示与导出
8、新增商品池导入：按内部编码 / 供应商编码匹配，找不到自动建商品，供应商不存在自动建并回填银行信息
9、新增商品表列显示开关：常用列 / 全部列 / 自定义
10、商品匹配规则升级：69码优先 → 别名 → 品名模糊匹配（但规格必须完全一致）

12、客户库按「客户信息表」12 列表头展示，新增导入与导出

14、订单按上传日期筛选：今天 / 本周 / 上周 / 本月 / 上月 + 具体日期，默认只看今天
15、订单明细新增「导出」标识与导出时间（已导出显示时间，未导出显示灰色）
16、详细地址列缩短显示，鼠标悬停查看完整地址
17、订单采集页布局重构：导入区、订单明细、导出入口更紧凑

【六、运单回填】

【七、对账】
